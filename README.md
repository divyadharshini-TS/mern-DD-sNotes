# DD'sNotes

DD'sNotes — a small MERN note-taking app (frontend + backend) created from a ThinkBoard fork and adapted for personal use.

Quick start

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev
```

Environment

- Backend expects `backend/.env` to contain `MONGO_URI` and optional Upstash vars.
- Frontend reads `VITE_API_URL` from `frontend/.env` (defaults to `http://localhost:5001/api`).
