# DD'sNotes (Frontend)

DD'sNotes is a lightweight MERN note-taking frontend built with React + Vite and DaisyUI/Tailwind for styling. This folder contains the client app used in development at `http://localhost:5173`.

Quick start

```bash
cd frontend
npm install
npm run dev
```

Build for production

```bash
npm run build
```

Notes

- The frontend reads API calls from `VITE_API_URL` (see `.env` in `frontend/`).
- The UI brand is `DD'sNotes`.
